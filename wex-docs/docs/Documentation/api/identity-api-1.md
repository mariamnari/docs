## Overview

The Identity API provides a way to generate a **person identifier**. This identifier connects information across multiple services securely and consistently.

## Why Use the API

* Ensures a single source of truth for person identity.
* Simplifies linking data across Person, Claims, and other APIs.
* Improves security by managing identifiers centrally.

## What Can the API Do

* Create a unique identifier for a person.
* Use the identifier to look up or update information about that person.

## Key Features

* Secure identifier creation.
* Cross-service identity consistency.
* Simple integration with other APIs.
