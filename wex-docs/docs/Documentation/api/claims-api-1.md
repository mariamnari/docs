## Overview

The Claims API enables management of the **full claims lifecycle**, from filing to repayment. It handles claim adjustments, reversals, receipts, payees, and expenses.

## Why Use the API?

* Streamlines claims processing for efficiency.
* Reduces manual effort by automating claim adjustments and reversals.
* Supports compliance by maintaining accurate claim and expense records.

## What Can the API Do?

* File, adjust, or reverse claims.
* Upload and retrieve receipts.
* Repay claims.
* Get payee and expense information.

## Key Features

* End-to-end claim lifecycle support.
* Receipt management (upload and retrieve).
* Expense tracking.
* Integrated repayment and payee management.
